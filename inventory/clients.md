**Role:** Portable administration and development client

| Architecture | x86-64 |
| Processor | Intel Core i7-8650U |
| Memory | 16 GB |
| Storage | 512 GB NVMe SSD |

### Responsibilities

Relic is a portable Linux workstation primarily used for administering and maintaining the Empire.

Its responsibilities include:

- Remote server administration via SSH
- Secure remote access using Tailscale
- Linux troubleshooting and maintenance
- Development and testing of personal applications
- Local virtualisation using GNOME Boxes
- Infrastructure documentation using VS Code and Git

### Notes

Relic is a client device rather than an infrastructure server. It does not provide essential services to other devices in the Empire.
